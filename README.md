\# 大整数乘法（Karatsuba 分治法）



\## 题目

给定两个非负大整数（位数可达 1000 位以上，超出 64 位整数范围），计算它们的精确乘积。



\- 输入：两行字符串，每行一个无前导零的大整数。

\- 输出：一行，两数乘积（无前导零，0 直接输出 0）。



\## 核心思想

Karatsuba 算法是一种分治算法，把大整数拆成高低位，用 \*\*3 次乘法\*\* 代替普通分治的 4 次乘法，从而降低时间复杂度。



设两个大整数为：

a = a1 \* 10^m + a0

b = b1 \* 10^m + b0



其中 `a0`、`b0` 是低 `m` 位，`a1`、`b1` 是高 `n-m` 位。



则：a \* b = z0 + z1 \* 10^m + z2 \* 10^(2m)



其中：



\- `z0 = a0 \* b0`

\- `z2 = a1 \* b1`

\- `z1 = (a0 + a1) \* (b0 + b1) - z0 - z2`



这样只需要计算 3 次乘法：`z0`、`z2`、`(a0+a1)\*(b0+b1)`。



\## 复杂度

\- 普通竖式乘法：O(n^2)

\- Karatsuba：O(n^(log2 3)) ≈ O(n^1.585)

\- 递归式：T(n) = 3T(n/2) + O(n)



\## 存储方式

采用 \*\*低位在前\*\* 的 `vector<int>` 存储大整数。



例如：



\- 整数 `123` 存为 `{3, 2, 1}`

\- 整数 `1200` 存为 `{0, 0, 2, 1}`



这样做的好处是进位从下标 0 开始向高位传递，处理方便。



\## 代码结构



| 函数名 | 作用 |

|--------|------|

| `trim` | 去掉高位的多余 0 |

| `add` | 高精度加法：`a + b` |

| `sub` | 高精度减法：`a - b`，保证 `a >= b` |

| `shift` | 左移 k 位，相当于乘以 `10^k` |

| `naiveMul` | 普通 O(n^2) 乘法，用于小规模递归基 |

| `karatsuba` | Karatsuba 分治乘法主体 |



\## 关键细节



\### 1. 高精度加法 `add`

\- 结果数组长度取 `max(a.size(), b.size()) + 1`，预留最高位进位。

\- `carry` 保存进位：每轮 `sum = carry + a\[i] + b\[i]`，`c\[i] = sum % 10`，`carry = sum / 10`。

\- 最后用 `trim` 去掉多余 0。



\### 2. 高精度减法 `sub`

\- 要求 `a >= b`。

\- 逐位相减，不够减时向高位借 1。

\- `borrow` 保存借位。



\### 3. 移位 `shift(a, k)`

\- 乘以 `10^k` 等价于在低位在前的数组 \*\*前面补 k 个 0\*\*。

\- 例如 `a = {3,2,1}` 表示 123，`shift(a, 2)` 得到 `{0,0,3,2,1}` 表示 12300。



\### 4. 普通乘法 `naiveMul`

\- 结果数组长度取 `a.size() + b.size()`。

\- 双重循环：`c\[i+j] += a\[i] \* b\[j]`，先累加不处理进位。

\- 最后从低位到高位统一处理进位。

\- 小规模（长度 <= 32）时直接用它，避免递归开销。



\### 5. Karatsuba 主体 `karatsuba`

\- 递归基：`min(a.size(), b.size()) <= 32` 时调用 `naiveMul`。

\- 取 `n = max(a.size(), b.size())`，`m = n / 2`。

\- 拆分：

&#x20; - `a0` 取 `a` 的前 `m` 位（低位），`a1` 取剩余高位。

&#x20; - `b0`、`b1` 同理。

\- 递归计算：

&#x20; - `z0 = karatsuba(a0, b0)`

&#x20; - `z2 = karatsuba(a1, b1)`

&#x20; - `z1 = karatsuba(add(a0,a1), add(b0,b1))`

&#x20; - `z1 = sub(z1, add(z0, z2))`

\- 合并：

&#x20; - `res = add(add(z0, shift(z1, m)), shift(z2, 2\*m))`

\- 最后 `trim`。



\## 易错点

1\. 结果数组长度：加法是 `max(len)+1`，乘法是 `len(a)+len(b)`。

2\. `carry` 是进位，每轮先加 `carry`，再算 `%10` 和 `/10`。

3\. `naiveMul` 先累加再统一进位，不要边乘边进位。

4\. 递归基阈值一般取 32 左右，太小递归开销大，太大退化成普通乘法。

5\. 输出前记得 `trim`，0 要输出 `0`。

6\. `sub` 必须保证 `a >= b`，否则会出错。

7\. `shift` 对 0 要特判，直接返回 `{0}`。



\## 手动模拟示例

计算 `1234 \* 5678`，取 `m = 2`：

a = 12 \* 10^2 + 34 (a1=12, a0=34)

b = 56 \* 10^2 + 78 (b1=56, b0=78)



z0 = 34 \* 78 = 2652

z2 = 12 \* 56 = 672

a0+a1 = 46, b0+b1 = 134

(a0+a1)\*(b0+b1) = 46 \* 134 = 6164

z1 = 6164 - 2652 - 672 = 2840



结果 = z0 + z1\*10^2 + z2\*10^4

= 2652 + 2840\*100 + 672\*10000

= 2652 + 284000 + 6720000

= 7006652



验证：`1234 \* 5678 = 7006652`，正确。
